A 4 KB Python chess engine: alpha-beta search with a transposition table, quiescence and null-move pruning, and a tapered evaluation. It plays the house gauntlet through the make.fun env over HTTP.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 -P -s main.py
```
